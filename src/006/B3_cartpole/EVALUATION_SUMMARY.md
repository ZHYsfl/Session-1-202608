# B3 Cart-Pole 正式实验评估总结

## 1. 实验范围

本记录基于 `outputs/formal/` 中已经生成的训练与评估文件，分析日期为
2026-07-30。正式协议使用 3 个训练种子（42、123、2026），每个学习模型
训练 70,000 个环境步；验证集使用 20 回合，开发集和最终测试集各使用
100 回合。每个方法的表格结果均为 3 个训练种子的均值 ± 样本标准差，
即每个 checkpoint 汇总 300 个评估回合。

成功定义为小车和杆保持有效状态直至 500 步。正式矩阵共完成 21 次训练，
累计 1,470,000 个环境步。运行环境为 Python 3.10.19、PyTorch
2.6.0+cu124 和 NVIDIA GeForce RTX 4060 Laptop GPU，配置哈希为
`80880e41dff4654dd1ce3917e5a020bf5f694ac5078cf7a29833ed5570ba7da7`。

## 2. 最终测试结果

以下主表只报告由验证集选择的 **best checkpoint**：

| 方法 | 平均步数 | 成功率 |
|---|---:|---:|
| Random policy | 20.53 ± 1.21 | 0.00% ± 0.00% |
| Standard DQN | 219.17 ± 64.01 | 0.00% ± 0.00% |
| + State normalization | 472.10 ± 48.32 | 84.33% ± 27.14% |
| + Double DQN | 406.49 ± 161.97 | 72.67% ± 47.34% |
| Full method | 469.99 ± 30.58 | 79.67% ± 26.27% |
| Q-Learning Coarse | 482.78 ± 9.10 | 82.67% ± 7.57% |
| **Q-Learning Medium** | **490.30 ± 9.94** | **91.67% ± 8.39%** |
| Q-Learning Fine | 381.90 ± 179.87 | 61.67% ± 53.69% |

### 主要结论

1. **Q-Learning Medium 是本次最佳方法。** 它比 Full method 多
   20.31 个平均步数，成功率高 12.00 个百分点，而且三个种子均达到
   82% 以上成功率。
2. **状态归一化是 DQN 最有效的改动。** 相比 Standard DQN，它提高
   252.93 个平均步数和 84.33 个成功率百分点。按均值和成功率计算，
   `+ State normalization` 也是当前表现最好的 DQN 变体。
3. **Double DQN 没有稳定带来增益。** 种子 42 和 2026 达到 100%
   成功率，但种子 123 只有 18%，导致平均步数标准差达到 161.97。
4. **加快探索衰减改善了 Double DQN 的稳定性。** Full method 的平均
   步数标准差降至 30.58，但性能仍略低于只加入状态归一化的 DQN。
5. **分箱并非越细越好。** Fine 分箱在种子 2026 上完全失败，说明
   70,000 步不足以稳定覆盖过大的离散状态空间；Medium 在表达能力与
   状态访问次数之间取得了更好平衡。

## 3. 开发集与最终测试集一致性

各方法 best checkpoint 的最终测试平均步数相对开发集只变化
`-9.49 ~ +6.74` 步。Q-Learning Medium 从 495.33/94.00% 变为
490.30/91.67%，Full method 从 475.41/81.33% 变为
469.99/79.67%。两组划分的结论一致，暂未发现明显的开发集过拟合。

最终测试 JSON 已经存在，说明封存测试集已经解封并执行。后续不得再根据
这些结果调整当前实验超参数后重复报告同一测试集；如需继续调参，应重新
指定一组从未使用过的测试种子。

## 4. 训练稳定性

| 方法 | Best 平均步数 | Final 平均步数 | 退化步数 |
|---|---:|---:|---:|
| Standard DQN | 219.17 | 90.01 | 129.16 |
| + State normalization | 472.10 | 124.33 | 347.77 |
| + Double DQN | 406.49 | 54.56 | 351.92 |
| Full method | 469.99 | 124.95 | 345.04 |
| Q-Learning Coarse | 482.78 | 327.44 | 155.34 |
| Q-Learning Medium | 490.30 | 341.33 | 148.97 |
| Q-Learning Fine | 381.90 | 202.55 | 179.35 |

所有方法都出现不同程度的训练后期退化，DQN 尤其严重，因此保存和报告
best checkpoint 是必要的。最优 checkpoint 出现在 5,000 至 70,000
步之间，且同一方法不同种子的最优时刻差异很大，不能用固定训练终点代替
验证集模型选择。曲线的大幅波动也说明“训练更久”不等于“策略更好”。

## 5. 计算开销

21 次训练记录的累计墙钟时间约为 55.16 分钟。单次 DQN 训练平均耗时约
220～379 秒，单次 Q-Learning 约 6 秒。该时间只反映当前实现和硬件，
因为神经网络批量更新与表格更新的计算量不同，不应把墙钟时间直接解释为
算法理论复杂度。

## 6. 报告建议与限制

- 主结果应报告 Q-Learning Medium 的 best checkpoint，并把
  `+ State normalization` 作为最佳 DQN 结果。
- 消融结论应写成“归一化显著有效；Double DQN 在当前配置下未稳定提升”，
  不应预设 Full method 一定最好。
- 同时报告 best/final 差距，诚实说明策略存在训练后期退化。
- 当前只有 3 个训练种子，标准差估计仍较粗；结论只适用于本项目自定义的
  Cart-Pole 环境。
- 500 步上限造成指标饱和，成功率比平均步数更容易区分接近满分的方法。
- best checkpoint 由 20 个验证回合选择，仍可能受验证样本较少影响。
- 回报主要由存活步数决定，不是独立指标，因此主表保留平均步数和成功率。
