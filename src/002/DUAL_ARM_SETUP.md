# SO-101 主从双机械臂连接指南

## 🤖 系统配置：双机械臂（主从模式）

**您的配置：**
- 主机械臂 (Leader) + 控制板
- 从机械臂 (Follower) + 控制板
- 每个控制板都有独立的USB接口

---

## 📌 双机械臂连接方案

### 方案选择

#### 推荐方案：只连接从机械臂 ⭐

**原因：**
- 对于逆运动学研究，只需要控制一个机械臂
- 从机械臂用于执行IK计算的结果
- 主机械臂通常用于遥操作演示（本项目不需要）

**连接方式：**
```
电脑 ←USB→ 从机械臂控制板 ←电源→ 12V适配器
```

#### 可选方案：连接两个机械臂

如果您需要：
- 主从遥操作演示
- 数据采集（主机械臂示教，从机械臂执行）
- 双臂对比实验

**连接方式：**
```
电脑 ←USB1→ 主机械臂控制板 ←电源1→ 12V适配器1
     ←USB2→ 从机械臂控制板 ←电源2→ 12V适配器2
```

## 🔄 如果需要使用双机械臂

### 双机械臂连接步骤

**场景：主从遥操作或数据采集**

#### 步骤1：连接两根USB线

```
电脑 USB端口1 → 主机械臂控制板
电脑 USB端口2 → 从机械臂控制板
```

#### 步骤2：识别端口

Windows会分配两个不同的COM端口，例如：
- 主机械臂：COM5
- 从机械臂：COM6

#### 步骤3：区分主从

**方法1：逐个测试**
```bash
# 只连接主机械臂USB，记录COM端口
python robot_control/test_connection.py
# 假设显示 COM5

# 断开主机械臂，连接从机械臂USB
python robot_control/test_connection.py
# 假设显示 COM6
```

**方法2：同时连接后标记**
```bash
# 两个都连接，然后扫描
python robot_control/test_connection.py

# 手动移动主机械臂的某个关节
# 读取两个端口的数据，数据变化的就是主机械臂

# 或在控制板上贴标签：A(主) / B(从)
```

#### 步骤4：配置文件

```yaml
# configs/robot_config.yaml
robot_control:
  leader_port: "COM5"    # 主机械臂
  follower_port: "COM6"  # 从机械臂
  baudrate: 1000000
```

## 🛠️ 实用脚本

### 创建单机械臂测试脚本

```python
# test_single_arm.py
"""测试单个机械臂连接"""

import serial.tools.list_ports

def find_robot_port():
    """自动查找机械臂端口"""
    ports = serial.tools.list_ports.comports()
    
    robot_ports = []
    for port in ports:
        # 查找USB串口（排除蓝牙）
        if 'USB' in port.description.upper() or 'CH340' in port.description.upper():
            robot_ports.append(port.device)
            print(f"✓ 发现机械臂: {port.device} - {port.description}")
    
    if len(robot_ports) == 0:
        print("✗ 未发现机械臂，请检查USB连接")
        return None
    elif len(robot_ports) == 1:
        print(f"\n✓ 自动选择: {robot_ports[0]}")
        return robot_ports[0]
    else:
        print(f"\n发现多个设备: {robot_ports}")
        print("请断开不需要的设备，或手动选择")
        return None

if __name__ == "__main__":
    port = find_robot_port()
    if port:
        print(f"\n下一步：")
        print(f"  python robot_control/scan_servos.py")
        print(f"  输入端口: {port}")
```

## ❓ 常见问题

**Q: 必须连接两个机械臂吗？**
A: 不需要。对于IK研究，一个机械臂就够了。

**Q: 主从机械臂有什么区别？**
A: 硬件相同，区别在于使用方式：
   - 主机械臂：用于示教（手动操作）
   - 从机械臂：用于执行（程序控制）

**Q: 如何区分哪个是主哪个是从？**
A: 
   - 查看标签或包装
   - 或随意指定一个作为主/从
   - 硬件完全相同，可互换

**Q: 两个机械臂会冲突吗？**
A: 不会。每个占用不同的COM端口，独立控制。

**Q: 后期可以再连接第二个吗？**
A: 可以。随时插拔USB，Windows会自动识别。
