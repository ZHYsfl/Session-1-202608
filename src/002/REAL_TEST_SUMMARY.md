## 💡 技术要点

### 舵机编码转换

```python
# 舵机值 → 弧度
radians = (servo_value - 2048) / 4096.0 * (240.0 * π / 180.0)

# 弧度 → 舵机值
servo_value = radians / (240.0 * π / 180.0) * 4096.0 + 2048
```

### 安全控制参数

```python
MAX_SPEED = 50      # 测试速度 (0-1023)
MAX_STEP = 100      # 单次最大移动量
NORMAL_SPEED = 300  # 正常工作速度
```

### FK验证方法

```python
1. 读取当前关节角 θ
2. 计算FK: P = FK(θ)
3. 手动测量实际位置 P_actual
4. 计算误差: error = ||P - P_actual||
5. 如果error < 20mm: 通过
```
