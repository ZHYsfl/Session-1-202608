### 问题1: FK关节顺序不匹配 🔴

**现象**: URDF中关节顺序与实际舵机ID不一致

**影响**: IK无法正确求解

**解决方案**:

```python
    2: 3,  # elbow_flex    (ID3) → URDF中第4个
    3: 2,  # wrist_flex    (ID4) → URDF中第3个
    4: 1,  # wrist_roll    (ID5) → URDF中第2个
}

def compute(self, joint_angles):
    # 重新映射关节角

```

### 问题2: 数值IK求解失败 🟡

**可能原因**:
1. FK模型不准确 → 目标位姿不可达
2. 初始猜测差 → 陷入局部最优
3. Jacobian计算错误 → 迭代方向错误
4. 关节限位过严 → 无解空间

**调试步骤**:
1. 验证FK正确性（已完成）
2. 测试"零移动"IK（当前位姿→当前位姿）
3. 逐步增大目标偏移量
4. 输出每次迭代的误差和关节变化

### 问题3: 位置控制精度不足 🟢

**现象**: 5-30步位置误差 (约0.3-2°)

**原因**: 开环控制 + 重力 + 摩擦

**影响**: 可接受（对于低成本机械臂）

**改进** (可选):
- 添加PID控制器
