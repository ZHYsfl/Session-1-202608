## 1. 训练好的神经网络有什么用

### 1.1 三种IK方法对比

| 方法 | 工作方式 | 优点 | 缺点 |
|------|---------|------|------|
| 解析IK | 套几何闭式公式直接算 | 极快、精确 | 依赖精确连杆参数；本项目3D打印臂参数不准 → 常无解 |
| 数值IK | 从初值迭代逼近(30~50次) | 通用，任何构型可用 | 慢；依赖初值；奇异点卡死 |
| **神经网络IK** | 一次前向传播直接输出 | 微秒级；不需精确模型参数 | 需训练数据；精度略低 |

### 1.2 神经网络IK在本项目的三大用处

**(1) 速度 — 支持实时控制**
数值IK每次迭代都要计算雅可比矩阵并解线性方程组，几十次循环累积到毫秒级。
神经网络只是几次矩阵乘法，**微秒级**。主从遥操作要 20~50Hz 实时刷新，神经网络才跟得上。

**(2) 绕过"参数测不准"的根本困难**
解析IK需要精确的连杆长度、关节零位偏置。本项目机械臂是 3D 打印 + 手工装配，
这些参数根本无法精确测量。神经网络**直接从真机数据学习**，把装配误差、舵机零位偏差、
重力下垂等真实效应全部"吸收"进网络权重。这正是"方案A(真实数据驱动)"的核心价值。

**(3) 论文的核心贡献**
课题是"逆运动学解析与神经网络的端到端实现方式对比"。训练好的网络就是"端到端"这一半，
用实验数据回答：神经网络能否达到可用精度？比数值法快多少？——这就是论文的实验结果。

> **一句话总结**：训练好的网络 = 一个又快、又不依赖精确模型参数的 IK 求解器，
> 是论文中与传统方法对比的主角。

## 2. 核心思想：神经网络在拟合什么函数

我们想学习一个映射函数 f：

```
f : (末端位姿, 当前关节角)  ──►  目标关节角
```

数学表达：

$$
f:\ (\mathbf{p}, \alpha, \psi,\ \mathbf{q}^{cur})\ \longmapsto\ \mathbf{q}^{target}
$$

其中：
- $\mathbf{p}=(x,y,z)$：末端目标位置
- $\alpha$：pitch(俯仰角)，$\psi$：roll(滚转角)
- $\mathbf{q}^{cur}=(q_1,...,q_5)$：当前 5 个关节角
- $\mathbf{q}^{target}=(q_1,...,q_5)$：要求解的目标 5 个关节角

### 为什么输入要带"当前关节角"？

因为 **IK 是多解问题**：同一个末端位置，机械臂"肘朝上"和"肘朝下"都能到达。
如果只给末端位姿，网络不知道该输出哪个解，会学成多个解的"平均"(物理上错误)。

带上当前姿态后，网络能学会"从现在这个姿势出发，选最接近的那个解"，从而消除歧义。

## 3. 输入表示的数学设计

网络输入是一个 12 维向量：

$$
\mathbf{x} = \big[\ \underbrace{x,\ y,\ z}_{\text{位置 3 维}},\
\underbrace{\sin\alpha,\ \cos\alpha}_{\text{pitch 2 维}},\
\underbrace{\sin\psi,\ \cos\psi}_{\text{roll 2 维}},\
\underbrace{q_1^{cur},\ q_2^{cur},\ q_3^{cur},\ q_4^{cur},\ q_5^{cur}}_{\text{当前关节 5 维}}\ \big]
$$

维度：3 + 2 + 2 + 5 = **12 维**。

### 关键设计：角度为什么拆成 sin/cos，不直接用角度值？

**问题**：角度有周期性。$-179°$ 和 $+181°$ 指向同一个方向，但数值上差 $360°$。
若直接把角度喂给网络，它会认为这两个输入天差地别，无法正确学习。

**解决**：把角度 $\theta$ 映射到单位圆上的一个点 $(\cos\theta, \sin\theta)$：

$$
\theta\ \longmapsto\ (\cos\theta,\ \sin\theta)
$$

这样 $-179°$ 和 $+181°$ 映射后几乎重合，**周期性天然满足**。
这是神经网络处理角度输入的标准技巧(angle encoding)。

> 注意：当前关节角 $q_i^{cur}$ 没有拆 sin/cos，因为它们被限制在有限范围内(不跨越±180°边界)，
> 直接用弧度值即可。

## 4. 数据转换公式推导（重点）

这是学习的核心：**如何把真机采集的原始数据，转换成网络能训练的样本**。

### 4.1 真机采集到的原始数据

采集脚本 `collect_real_data.py` 每次记录一条：

$$
(\mathbf{q}^{real},\ \mathbf{p}^{real})
$$

- $\mathbf{q}^{real}$：机械臂**实际到达**的 5 个关节角(弧度)
- $\mathbf{p}^{real}$：对应的末端把手尖端位置(米)

但网络需要的训练样本格式是 $(\mathbf{x},\ \mathbf{q}^{target})$，两者不同，需要转换。

### 4.2 转换公式(逐条推导)

**(a) 目标关节角 = 真机实际到达角**

真机实际到达的角就是这个位姿的"标准答案"：

$$
\boxed{\ \mathbf{q}^{target} = \mathbf{q}^{real}\ }
$$

**(b) 位姿用 FK 的 task-space 定义重算**

为保证与数值IK求解器度量一致，位姿必须用同一个 `compute_task_space` 计算：

$$
\boxed{\ (\mathbf{p},\ \alpha,\ \psi) = FK_{task}(\mathbf{q}^{real})\ }
$$

其中 task-space 定义：$\alpha$ = 工具 z 轴与水平面夹角，$\psi = q_5$(末关节)。
(⚠️ 若用其他欧拉角定义会导致数值IK不收敛，见 IK 一致性说明)

**(c) 当前关节角 = 目标角 + 高斯噪声(转换的精髓)**

真机数据里没有"当前角"这个量，我们**人工构造**它。方法是给目标角加高斯噪声：

$$
\boxed{\ \mathbf{q}^{cur} = \mathbf{q}^{target} + \boldsymbol{\epsilon},\qquad
\boldsymbol{\epsilon}\sim\mathcal{N}(0,\ \sigma^2 I),\quad \sigma=0.08\ \text{rad}\ }
$$

**为什么这样做？**
模拟真实使用场景：机械臂当前在姿态 $\mathbf{q}^{cur}$，你想让末端去到 $(\mathbf{p},\alpha,\psi)$，
网络应输出精确的 $\mathbf{q}^{target}$。加噪声就是模拟"当前姿态离目标有几度偏差"。
$\sigma=0.08$ rad $\approx 4.6°$，代表当前姿态在目标附近小幅晃动。

**(d) 数据增强：每条真机样本生成多份**

每条真机样本用不同的噪声 $\boldsymbol{\epsilon}$ 生成 $K=3$ 份训练样本，
让网络见过"从不同近邻出发都要收敛到同一目标"：

$$
N_{train} = N_{real} \times K = 600 \times 3 = 1800\ \text{条}
$$

这样网络学到的是一个**鲁棒的邻域映射**：无论当前姿态偏一点点，
只要给定目标位姿，都能输出正确的目标关节角。

### 4.3 最终输入向量组装

把上面算出的量按第 3 节的格式拼成 12 维输入：

$$
\mathbf{x} = [\ p_x,\ p_y,\ p_z,\ \sin\alpha,\ \cos\alpha,\ \sin\psi,\ \cos\psi,\
q_1^{cur},\ q_2^{cur},\ q_3^{cur},\ q_4^{cur},\ q_5^{cur}\ ]
$$

配对的监督标签为 $\mathbf{q}^{target}$。这就是一条完整训练样本 $(\mathbf{x},\ \mathbf{q}^{target})$。

### 4.4 数据集切分

$$
\text{train} : \text{val} : \text{test} = 70\% : 15\% : 15\%
$$

- **train**：训练网络权重
- **val**：训练中监控泛化、触发早停(early stopping)
- **test**：训练后评估最终性能(论文报告的数字)

## 5. 网络结构与限位约束

### 5.1 MLP 结构

```
输入(12) → Linear(256) → BatchNorm → ReLU → Dropout(0.1)
         → Linear(256) → BatchNorm → ReLU → Dropout(0.1)
         → Linear(128) → BatchNorm → ReLU → Dropout(0.1)
         → Linear(5)   → tanh
         → 缩放到关节范围 → 输出目标关节角(5)
```

- **BatchNorm**：归一化每层输入，加速收敛、稳定训练
- **ReLU**：非线性激活，$\text{ReLU}(x)=\max(0,x)$
- **Dropout(0.1)**：训练时随机丢弃 10% 神经元，防止过拟合

### 5.2 输出层的限位约束(优雅的硬约束)

最后一层用 $\tanh$，输出范围 $[-1,1]$，再线性缩放到关节物理范围：

$$
\boxed{\ \mathbf{q}^{pred} =
\underbrace{\frac{\mathbf{q}_{upper}+\mathbf{q}_{lower}}{2}}_{\text{中点}}
+ \underbrace{\frac{\mathbf{q}_{upper}-\mathbf{q}_{lower}}{2}}_{\text{半幅}}
\cdot \tanh(\mathbf{z})\ }
$$

其中 $\mathbf{z}$ 是网络最后一层线性输出。

**为什么这保证不超限位？**
因为 $\tanh(\mathbf{z}) \in [-1, 1]$，所以：
- 当 $\tanh=-1$：$\mathbf{q}^{pred} = \text{中点} - \text{半幅} = \mathbf{q}_{lower}$
- 当 $\tanh=+1$：$\mathbf{q}^{pred} = \text{中点} + \text{半幅} = \mathbf{q}_{upper}$

$\mathbf{q}^{pred}$ **数学上永远落在 $[\mathbf{q}_{lower}, \mathbf{q}_{upper}]$ 内**，
网络物理上不可能输出超限角度。这是硬约束，无需额外惩罚。

## 6. 损失函数

训练目标是最小化多分量损失：

$$
\boxed{\ \mathcal{L} = w_1\underbrace{\|\mathbf{q}^{pred}-\mathbf{q}^{target}\|^2}_{\text{关节角 MSE}}
+ w_4\underbrace{\mathcal{L}_{limit}}_{\text{限位余量惩罚}}\ }
$$

### 6.1 关节角 MSE(主项)

$$
\mathcal{L}_{joint} = \frac{1}{5}\sum_{i=1}^{5}(q_i^{pred}-q_i^{target})^2
$$

对真机数据，$\mathbf{q}^{target}$ 就是真值，所以直接回归关节角即可。

### 6.2 限位余量惩罚(正则项)

惩罚太靠近关节极限的解(留安全余量 $m=0.1$ rad)：

$$
\mathcal{L}_{limit} = \frac{1}{5}\sum_{i=1}^{5}
\Big[\ \text{ReLU}(q_{lower,i}+m - q_i^{pred})^2
+ \text{ReLU}(q_i^{pred} - (q_{upper,i}-m))^2\ \Big]
$$

- 若预测角在安全区内：两个 ReLU 都为 0，无惩罚
- 若预测角太靠近上/下限：产生正的平方惩罚，推动网络远离极限

### 6.3 权重设置

- $w_1$ (joint_weight) = 1.0：主任务
- $w_4$ (joint_limit_margin_weight) = 0.1：轻正则

> 说明：模型代码里还预留了位置损失 $w_2\|FK(\mathbf{q}^{pred})-\mathbf{p}\|^2$ 和
> 姿态损失。但对真机数据，target 就是实测真值，直接回归关节角已足够，
> 训练时未启用这两项(退化为纯关节回归 + 限位正则)。

## 7. 完整数据流总结

```
┌─────────────────────────────────────────────────────────────┐
│ 阶段1: 真机采集 (collect_real_data.py)                        │
│   随机安全配置 → 机械臂移动 → 读实际关节角 q_real            │
│                                → FK算末端位置 p_real          │
│   输出: real_robot_dataset.h5  (q_real, p_real) × 600         │
└─────────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────────┐
│ 阶段2: 数据转换 (convert_real_data.py)                        │
│   q_target = q_real                                           │
│   (p, α, ψ) = FK_task(q_real)                                 │
│   q_cur = q_target + 高斯噪声(σ=0.08)   ← 每条×3增强          │
│   x = [x,y,z, sinα,cosα, sinψ,cosψ, q_cur(5)]  (12维)         │
│   切分 train/val/test = 70/15/15                              │
│   输出: data/ik_dataset.h5  (x, q_target) × 1800              │
└─────────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────────┐
│ 阶段3: 训练 (train_network.py)                                │
│   IKNet: 12 → 256 → 256 → 128 → 5, tanh限位缩放              │
│   Loss = MSE(q_pred, q_target) + 0.1·限位惩罚                 │
│   Adam优化, ReduceLROnPlateau调度, 早停                       │
│   输出: models/ik_mlp_best.pth                                │
└─────────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────────┐
│ 阶段4: 真机验证 / 方法对比 (评估脚本)                         │
│   在test集上比较: 解析IK vs 数值IK vs 神经网络IK              │
│   指标: 成功率、位置误差(mm)、推理时间(ms)                    │
│   → 论文实验结果                                              │
└─────────────────────────────────────────────────────────────┘
```
