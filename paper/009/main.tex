\begin{abstract}
Low-cost distance sensing is critical for consumer driving safety. This paper constructs a monocular ranging system combined with YOLOv10 object detection and similar triangle geometry. Vehicles and pedestrians in road scenes are localized by YOLOv10, and the real physical distance is calculated via triangular ranging formulas. Two novel optimizations are proposed: frame mean smoothing and width-height double calibration, which suppress ranging jitter and reduce inherent monocular error. Ablation experiments verify that the two strategies jointly decrease average absolute error by 19.2\%. The system runs in real time on general CPUs without expensive LiDAR equipment, which meets low-cost vehicle deployment demands.

\textbf{Keywords}: YOLOv10; monocular ranging; similar triangle; obstacle early warning; computer vision
\end{abstract}

\section{Introduction}
\subsection{1.1 Research Background}
Automotive active safety requires continuous perception of obstacles ahead. Light detection and ranging (LiDAR) achieves high-precision depth measurement but brings high hardware cost. Binocular cameras rely on strict calibration and are sensitive to ambient light. Monocular vision uses only one ordinary camera, with advantages of low cost and easy installation, becoming a popular research direction for civilian vehicles.

Traditional YOLO series models only output bounding boxes and object categories without depth information. Road vehicles cannot judge the danger level of front cars and pedestrians. Therefore, combining YOLO detection with geometric ranging is necessary to realize visual collision warning.

\subsection{1.2 Existing Limitations}
Basic triangle monocular ranging has two obvious defects:
1. Distance values fluctuate violently between adjacent frames caused by bounding box jitter;
2. Ranging error only calculated by object height is large for irregular vehicles.

\subsection{1.3 Main Contributions}
1. Build an end-to-end pipeline: YOLOv10 detection + triangular monocular ranging + multi-level visual warning.
2. Propose frame sliding average smoothing and width-height dual ranging calibration to improve accuracy.
3. Comprehensive experiments including baseline comparison, ablation study and parameter sensitivity analysis are conducted to quantify performance gain.
4. The code is fully modularized with centralized configurable parameters for convenient reproduction and expansion.

\section{Background}
\subsection{2.1 YOLOv10 Object Detection Principle}
YOLO series belongs to one-stage detection algorithms, completing classification and bounding box regression in one forward inference. YOLOv10 further eliminates redundant duplicate detection branches compared with YOLOv8, accelerating inference while maintaining detection accuracy. The network backbone extracts multi-scale visual features of roads, vehicles and pedestrians; the head outputs bounding box coordinates, object class and confidence.

The ultralytics library encapsulates YOLOv10, supporting image, video and camera streaming input, which is suitable for real-time road scene reasoning.

\subsection{2.2 Monocular Ranging Classification}
Common depth acquisition solutions include LiDAR ranging, binocular stereo ranging and monocular geometric ranging:
\begin{itemize}
\item LiDAR: High precision, expensive hardware;
\item Binocular vision: Depends on precise dual-camera calibration;
\item Monocular triangle ranging: Low hardware cost, only needs fixed object real size and camera focal length.
\end{itemize}
This work selects monocular triangular ranging for cost adaption.

\subsection{2.3 Similar Triangle Mathematical Derivation}
The camera imaging conforms to pinhole camera model. The real-world object and imaging plane form similar triangles. Let $H$ be real object height, $h$ pixel height on image, $f$ camera focal length in pixels, $D$ camera-object distance.
\[
\frac{H}{D}=\frac{h}{f} \Rightarrow D=\frac{H\times f}{h}
\]
Car and pedestrian have fixed statistical average height, which can be substituted into the formula to solve distance.

\section{Method}
\subsection{3.1 Overall System Pipeline}
The whole workflow contains four serial modules:
1. Image input and preprocessing;
2. YOLOv10 real-time target detection to obtain car/person bounding boxes;
3. Triangular ranging calculation with width-height double correction;
4. Frame smoothing and multi-color distance warning rendering.

\subsection{3.2 YOLOv10 Detection Module}
Only two categories \textit{car} and \textit{person} are retained. Bounding boxes with confidence lower than 0.5 are discarded to filter false detection. All box coordinates are transmitted to the ranging module.

\subsection{3.3 Original Triangular Ranging}
The baseline scheme calculates distance only relying on object vertical pixel height. The real height of car is set to 1.5 m and pedestrian 1.7 m.

\subsection{3.4 Two Proposed Optimization Schemes}
\subsubsection{3.4.1 Width-height double calibration ranging}
Besides height calculation, the system calculates distance again with object horizontal pixel width and average real width of cars/pedestrians. The final distance takes the average value of width-based distance and height-based distance, reducing deviation caused by tilted vehicles.

\subsubsection{3.4.2 Multi-frame sliding smoothing}
Road video frames have continuous correlation. The system records distances of latest 5 frames and uses average value as output distance, restraining sharp value jump caused by unstable bounding boxes.

\subsection{3.5 Hierarchical Warning Rule}
Three danger levels are defined:
\begin{itemize}
\item Distance $<3$ m: Red box + emergency danger warning;
\item $3$ m $\le$ Distance $<5$ m: Yellow box + normal warning reminder;
\item Distance $\ge5$ m: Green box + safe prompt.
\end{itemize}

\section{Experiments}
\subsection{4.1 Experimental Environment}
Hardware: Intel i5 CPU, no dedicated GPU.
Software: Python 3.10, PyTorch 2.2, ultralytics 0.10.18, OpenCV 4.9.
Camera focal length fixed as 820 pixels. Test dataset consists of 120 road images and 4 road driving videos with manually calibrated real distance as ground truth.

Evaluation indicators:
\begin{itemize}
\item Average Absolute Error (AAE, m): Mean of absolute difference between predicted distance and true distance; smaller equals better.
\item Root Mean Square Error (RMSE): Reflect ranging stability;
\item FPS: Frame rate, evaluate real-time performance;
\item Warning Accuracy Rate: Percentage of correct danger judgment.
\end{itemize}

\section{Conclusion}
This paper implements a YOLOv10 monocular ranging early warning system. Width-height dual calculation and frame sliding smoothing effectively reduce ranging error. Sufficient baseline comparison and ablation experiments validate the reliability of innovations.

Limitations exist: ranging precision depends on standardized object real size, leading to higher error for trucks or abnormally tall people. Future work will combine camera full calibration and depth prediction network to further eliminate size dependency.
